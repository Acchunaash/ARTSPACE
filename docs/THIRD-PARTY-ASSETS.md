# Third-party 3D clothing assets

ARTSPACE loads the following prebuilt garment GLB files from the CharacterCreator project:

- Source repository: https://github.com/kblood/CharacterCreator
- Garment files: `output/clothing_dress.glb`, `output/clothing_skirt.glb`, `output/clothing_jeans.glb`, and `output/clothing_hoodie.glb`.
- Asset licence: CC0-1.0, as stated in the source repository's `LICENSE-NOTES.md` for generated garment GLBs.
- Runtime source URLs use the upstream `master` branch on raw.githubusercontent.com.

The CharacterCreator generator code is GPL-3.0-or-later; ARTSPACE uses only the separately licensed generated GLB data and does not copy or bundle the generator code.

Source licence notes: https://github.com/kblood/CharacterCreator/blob/master/LICENSE-NOTES.md
